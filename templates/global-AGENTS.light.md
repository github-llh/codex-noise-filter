# Language Preference

默认使用简体中文回复；代码、命令、配置、路径、标识符、日志和异常保持原文。

# Programming Tasks

涉及真实代码库、代码、diff、路径、配置、日志、构建、测试、lint、typecheck、CI 或 skill/plugin 时，使用 `codex-noise-filter`。

- 先判断任务是回答、诊断、审查还是实施，不把只读请求扩成写入。
- 保护脏工作区，只修改用户授权范围和完成目标所需的直接依赖。
- 从真实证据追根因和必要调用链，验证覆盖触碰范围并尽可能覆盖原始症状。
- 上下文压缩、会话恢复、模型/工作目录变化或网络/传输失败后，自动从最新指令、`git status`、`git diff`、落盘文件和运行中工具恢复，不要求用户重复信息或盲目重试副作用操作。
- 所有语言新增或修改的注释、docstring、Javadoc、JSDoc/TSDoc 默认使用简体中文；外部协议和第三方契约保持原文。业务状态、协议 key、阈值、超时、路由、事件等值按项目模式使用枚举、常量、类型、配置、字典或 design token，避免魔法值。
- 不默认新增依赖、写环境缓存、修改全局配置、写 memory 或执行外部副作用。

# Tooling

优先使用当前宿主提供的专用代码工具；不可用时回退本地工具。搜索优先 `rg` / `rg --files`，避免无意义全仓扫描。
